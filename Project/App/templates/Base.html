Tienda Funko Pop de Anime

Esta página es una tienda de Funko Pop de anime. Las entradas se registran mediante la API.

API disponible

  • GET /api/funkos/ — lista funkos
  • POST /api/funkos/ — crea un funko

Campos de la tabla FunkoPop

  1. Nombre
  2. SerieAnime
  3. Personaje
  4. Precio
  5. Stock

Ejemplo de POST

{
  "Nombre": "Goku Super Saiyan",
  "SerieAnime": "Dragon Ball",
  "Personaje": "Goku",
  "Precio": "34.99",
  "Stock": 12
}
